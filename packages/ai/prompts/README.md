# プロンプト置き場

`docs/AI解析プロンプト集.md` の本文をそのまま実装に落とした場所（タスク2-3）。

- `system.ts` — 全プロンプト共通のシステムプロンプト（§0-2）
- `user_template.ts` — ユーザープロンプトの共通の型（§0-3）を組み立てる関数
- `basic_info.ts` / `qualifications.ts` / `lots.ts` / `forms.ts` / `notes.ts` / `questions.ts`
  — プロンプト6本（基本情報と期限／参加資格と参加条件／数量表の構造化と業種割当／
  提出書類の抽出／注意事項の抽出／質問案の生成）の出力スキーマ説明文と追加の指示

対応する出力スキーマ（Zod）は `../src/schemas/` に置いている。呼び出し可能な関数として
組み立てたものは `../src/analyze.ts` を参照。

**プロンプト7（見積返信のパース）はタスク4-3（返信の受信と金額の抽出）で実装する。**
このタスク（2-3）のスコープ外。
