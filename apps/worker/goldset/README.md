`goldset:template` が作る `goldset.json` を、人が正解で埋めてここに置く。

**このファイルはコミットする。** 公告を1件ずつ読んで作る正解なので、
失うと同じ作業をやり直すことになる。中身は公開されている入札公告の情報で、
秘密にすべきものは入らない。

作りかたと測りかたは `docs/reference/精度の測りかた.md` を見る。

## 何がどこまで確かめてあるか

`note` に、その案件をどこまで確かめたかを書く。混ぜると、後から見た人が
「原文で確かめた正解」だと誤解する。

| 書き出し | 意味 |
|---|---|
| `原文で確認（日付）：` | 公告を開いて突き合わせた。**これが本当の正解** |
| `引用のみで確認（原文は未確認）：` | 解析結果の引用と保存値が矛盾しないことだけを見た |
| （`checked` が空） | 引用が無い・引用が値を裏付けていないため、1項目も測っていない |

**引用のみの確認は、引用そのものが正しいかを保証しない。** 別の箇所を引いていても、
値と引用が揃っていれば矛盾しない。取り逃し（`（無し）`）も見つからない。
期限は失格に直結するので、引用が付いていても原文と照らす価値がある。
