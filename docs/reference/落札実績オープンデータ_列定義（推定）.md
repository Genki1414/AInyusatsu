# 落札実績オープンデータ 列定義（推定・未検証）

**この文書は、CSVの実データを直接確認せずに作成した推定です。** タスク1-8の制約により、
`docs/落札実績オープンデータ_取り込み設計.md` の A-1（仕様書PDFの確認）を経ずに実装したため、
実データで検証したら**必ずこの文書と `packages/domain/src/awards.ts` の `COLUMN_MAP` を合わせて更新してください。**

## 1. 確認できていないこと（要ローカル確認）

1. **zipファイルの実際の配置元URL**（ドメイン以下のパス）。
   本セッションのネットワークポリシーで `www.p-portal.go.jp` への到達がブロックされており
   （プロキシログ: `gateway answered 403 to CONNECT (policy denial)`）、ダウンロードページを
   直接確認できませんでした。ブラウザでダウンロードリンクのURLを確認し、
   環境変数 `AWARDS_OPEN_DATA_BASE_URL`（ファイル名を除いた部分）に設定してください。
   例: `https://www.p-portal.go.jp/pps-web-biz/.../files` のような形を想定。
2. **CSVの実際のヘッダ名**（列名）。以下の推定表はすべて未検証です。

## 2. 列名マッピング（推定・要検証）

`packages/domain/src/awards.ts` の `COLUMN_MAP` と対応します。政府調達オープンデータで
一般的に使われる項目名から推定しました。実データのヘッダを確認したら、**このファイルと
`COLUMN_MAP` を両方更新してください**（コードとドキュメントの2箇所を必ず揃える）。

| 内部フィールド名 | 推定ヘッダ名 | 用途・備考 |
|---|---|---|
| `procurementNo` | `調達案件番号` | 冪等キー（`opened_at`と組み合わせてawardsの一意制約） |
| `agencyName` | `調達機関名称` | `classifyAgencyClass()`で機関区分に変換（生の名称はDBに保存しない） |
| `itemName` | `品目分類名称` | `classifyItem()`で自社の営業品目辞書に変換（生の名称はDBに保存しない） |
| `budget` | `予定価格` | 非公表は「非公表」等の文字列を想定。数値化できなければ`disclosed=false` |
| `budgetTaxIncluded` | `予定価格税区分` | `amountTaxIncluded`が無い場合のフォールバック |
| `amount` | `落札金額` | これが取れない行は保存しない（`skipReason: amount_missing`） |
| `amountTaxIncluded` | `落札金額税区分` | 「税込」「税抜」の文字列を想定。それ以外は`taxUnknown=true` |
| `contractType` | `契約方式` | 総額／単価／複数年度 等をそのまま文字列で保存 |
| `bidders` | `入札者数` | 数値。無ければnull |
| `openedAt` | `落札日` | `normalizeDate()`で `YYYY年M月D日` / `YYYY/M/D` / `YYYYMMDD` をISO日付に変換 |

## 3. 品目分類の対応表（推定・キーワード方式）

`classifyItem()`（`packages/domain/src/awards.ts`）の実装。品目分類名称にキーワードが
含まれていれば分類し、当てはまらなければ `null`（=推測せず、market_ratesの集計対象から除外）。

| キーワード（正規表現） | 分類先（自社の営業品目辞書） |
|---|---|
| 清掃／環境衛生／建物管理 | 建物管理等 |
| 警備 | 警備 |
| 植栽／緑地 | 植栽等管理 |
| 什器／備品／机／椅子 | 什器類 |
| 情報処理／システム／ソフトウェア | 情報処理 |
| 理化学／実験用機器 | 理化学機器 |

**未対応の品目（什器類以外の物品、給食、運送 等）は、実データを見ながら追加してください。**

## 4. 機関区分の対応表（推定・ヒューリスティック）

`classifyAgencyClass()`（`packages/domain/src/awards.ts`）の実装。

| パターン | 機関区分 |
|---|---|
| 「独立行政法人」「国立大学法人」「特殊法人」「機構」を含む | 独立行政法人等 |
| 「財務局」「地方整備局」「防衛局」「厚生局」「森林管理局」「労働局」「地方支分部局」「事務所」「出張所」を含む | 地方支分部局 |
| 「省」「庁」で終わる | 本省 |
| 上記いずれにも当てはまらない | null（機関区分不明。market_ratesの集計対象から除外） |

**機関マスタ（`docs/機関マスタ_v2.md`）と名寄せする本格的な対応表は未実装です。** 現状は
オープンデータの機関名称文字列から直接ヒューリスティックで分類しており、`awards.agency_id`
（agenciesテーブルへの外部キー）は設定していません。

## 5. 正規化のルール（実装済み・`packages/domain/src/awards.ts`）

- 金額：`,` `，` `円` と空白を除去して数値化。`非公表` は `null`
- 日付：和暦は非対応（`令和8年7月22日`はnull）。西暦の `YYYY年M月D日` / `YYYY/M/D` / `YYYYMMDD` のみ対応
- 落札率：`予定価格`が取れる場合のみ `落札金額 ÷ 予定価格`（小数第4位で丸め）
- 外れ値：落札率が0.5未満または1.0超で `outlier=true`（集計除外）
- 税区分：「税込」「税抜」の文字列一致のみ判定。それ以外は `taxUnknown=true`（集計除外）
- 再度公告・不調：`market_rates`集計時のみ、同一 `procurement_no` は `opened_at` が最新の行だけを採用
  （`awards`テーブル自体には複数行が残る）
- 保存対象外（DBに書かない）：`落札金額`が取れない行、`調達案件番号`が取れない行
  （後者は冪等キーが立たず、再取込のたびに重複しうるため）
